## ATT&CK Mapping Note

The primary source's own ATT&CK mapping is loose (e.g. it labels the npm lifecycle hook as `T1053` Scheduled Task/Job). This test assigns accurate technique IDs: the headline technique is `T1195.002` (Compromise Software Supply Chain), JavaScript/Unix-shell execution is `T1059.007`/`T1059.004`, credential access is `T1552.001/.004/.005`, guardrails are `T1480.001`/`T1497.001`, and exfiltration is `T1071.001`/`T1041` with a `T1567.001` code-repository fallback.
