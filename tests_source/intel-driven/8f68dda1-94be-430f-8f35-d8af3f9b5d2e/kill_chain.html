Safety boundaries — real telemetry, contained effects

The chain exercises detection surfaces without reproducing a functional EDR killer, credential dump, production ransomware impact, or external command-and-control.

Driver containment: authentic rwdrv.sys is present only for signature inspection and is deleted before load attempts. Service and NtLoadDriver operations use nonfunctional stand-ins; no vulnerable driver is loaded.

Kernel simulation: all 320 process/thread/image callback removals are state changes in ARTIFACT_DIR\Qilin\callback_registry.json. No kernel callback is touched.

Process containment: termination and injection target only test-owned stand-ins, including the test-owned svchost.exe. Production security services and Windows svchost instances are not targeted.

Credential boundary: LSASS activity stops at the OpenProcess handle request. There is no ReadProcessMemory call, credential extraction, or memory dump.

Impact sandbox: only synthetic files under ARTIFACT_DIR\Qilin\impact are encrypted. Recovery commands target nonexistent volume/BCD identifiers, and the sandbox is removed during cleanup.

No external effects: no external egress, C2, lateral movement, production-target encryption, shadow-copy deletion, or boot-configuration change is performed.
