## Realism Lifts (vs. baseline simulation)

**LIFT 1 — Real `LoadLibraryW` in Stage 2.** A separate Go binary
(`sideload_host/main.go`) is built into a small signed EXE named
`LogiAiPromptBuilder.exe` and embedded gzip-compressed. At runtime, Stage 2
extracts the host EXE alongside a renamed copy of `C:\Windows\System32\version.dll`
(renamed to `screen_retriever_plugin.dll`) into `ARTIFACT_DIR\LogiAI\`, then
executes the host. The host performs a real `LoadLibraryW(screen_retriever_plugin.dll)`
producing genuine image-load telemetry on the renamed Microsoft DLL from a
non-standard path. Worth +1.0 on API Fidelity and +0.5 on Telemetry Signal Quality
vs. a placeholder simulation.

**LIFT 2 — Real `CoCreateInstance(CLSID_TaskScheduler)` in Stage 4.** Stage 4
opens COM via `CoInitializeEx`, then calls `CoCreateInstance` with the real
TclBanker CLSID `{0F87369F-A4E5-4CFC-BD3E-73E6154572DD}` and `IID_IUnknown`,
producing the exact COM-create-instance telemetry signal an EDR sees on real
TclBanker execution. The actual task XML registration is done via `schtasks
/create /xml` for reliability — the COM path provides the load-bearing telemetry,
the XML path provides reliable task creation. Triple cleanup: deferred
`cleanupTask("deferred")` + 10-second watchdog goroutine + final
`schtasks /delete /tn RuntimeOptimizeService /f` fallback. Worth +1.0 on API
Fidelity and +0.5 on Identifier Fidelity.
