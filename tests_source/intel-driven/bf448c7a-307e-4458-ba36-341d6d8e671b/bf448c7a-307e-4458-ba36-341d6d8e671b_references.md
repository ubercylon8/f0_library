### Source Coverage

The Elastic article provides the load-bearing intelligence for every identifier
and technique in this test:

- **Initial-access vector**: ZIP-wrapped MSI installer impersonating signed
  Logitech Update branding
- **Sideload host EXE name**: `LogiAiPromptBuilder.exe`
- **Sideloaded DLL name**: `screen_retriever_plugin.dll`
- **Install path shape**: `%LocalAppData%\LogiAI\`
- **.NET Reactor-protected payloads**: `Tcl.Agent`, `Tcl.WppBot` (assembly
  namespaces, not Tcl scripting language)
- **Scheduled task name**: `RuntimeOptimizeService`
- **Task Scheduler COM CLSID**: `{0F87369F-A4E5-4CFC-BD3E-73E6154572DD}`
- **Campaign GUID**: `70e4f943-e323-4484-97d7-35401bf6812c`
- **C2 infrastructure**: Cloudflare Workers, account `ef971a42`
- **C2 protocol**: WebSocket on `/ws` + HTTPS API, HMAC-SHA256-signed handshakes
- **Browser-monitoring API**: UI Automation (`IUIAutomation`)
- **Overlay-fraud pattern**: WPF full-screen overlays with Portuguese vishing
  strings such as "Estamos entrando em contato"
- **Debug artifact path**: `C:\temp\tcl-debug.txt`
